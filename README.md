# Xudong Luo — personal research page

A self-contained, responsive website for https://billrontac-cell.github.io/.

## Upload to GitHub

1. Open https://github.com/billrontac-cell/billrontac-cell.github.io and select the `main` branch.
2. Upload `index.html`, `style.css`, `script.js`, `.nojekyll` and the complete `assets` folder into the repository root. Do not upload the enclosing `personal-site` folder or ZIP file. Replace existing files with the same names if appropriate for your current site.
3. Commit the changes to `main`. If Pages is already configured for this branch and root directory, the site will update after deployment. Otherwise, select `main` and `/ (root)` in the repository's Pages settings under branch deployment.

No build, package installation, API key or external font is needed. Open `index.html` locally to preview. If your repository already has a framework or deployment workflow, integrate these files with that setup before replacing it; the existing repository could not be retrieved during preparation.

## Editing

Edit the text in `index.html`. Colours, spacing and mobile styles are in `style.css`. Images open in an accessible dialog; project details use native disclosure controls. All content remains readable without JavaScript.

The content uses your CV and personal statement materials. Dissertation results are simulation results, not published findings or real-flight results. Group work and your individual contributions are distinguished. The unfinished Wi-Fi project is labelled accordingly.

Only project images and public contact links are bundled. Your application CV (which includes your address, phone and immigration details), application statement and source reports are not included. No publication, paper link or public code repository is invented.

Before publishing, review the project descriptions and images for any material your collaborators or supervisor have not cleared for public sharing. Update ongoing roles and results as your work develops.
